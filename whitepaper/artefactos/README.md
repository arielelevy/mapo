# Artefactos

Documentos visuales del proyecto, como HTML autocontenido: se abren directo en el
navegador (doble click), sin servidor ni dependencias — todo el CSS va inline y las
fuentes caen a stacks del sistema si no hay red.

Cada uno existe también como Artifact publicado en claude.ai (URL estable, se
actualiza en el lugar); la copia de acá es la de registro, versionada con el repo.

**División de trabajo con los README**: los README (Markdown) son la fuente de verdad
dentro del repo — GitHub los renderiza, los artefactos HTML no. Los artefactos son el
documento vivo visual: enlazan desde los README y se abren locales con doble click.
**Cuándo se actualizan**: al cierre de cada fase de trabajo se republica el artefacto
(misma URL) y se refresca esta copia; no se sincronizan solos con el repo. En la
terminal, `ctrl+]` reabre el último artefacto y `/artifacts` lista todos.
