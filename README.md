# mapo

A deterministic decision layer for LLM agents, and the paper that validates it.

- **[`engine/`](engine/README.md)** — the product: arithmetic feasibility →
  beliefs with provenance → per-request assurance dial (A0–A3) → selective
  routing with abstention → accounting circuit breakers → EXPLAIN artifact.
  The measurement harness, corpora, registered predictions and verdicts live here.
- **[`paper/`](paper/README.md)** — the whitepaper. Written second, from the
  engine's measured record: nothing enters the paper without an implementation
  that runs it.
